# 零跑 B01 实车音频链路与车机音效档案

本文件记录**车机侧**的事实与参数，回答「App 该做什么、车机该做什么」。App 侧的动态处理见
[R95-AUDIO-V3-NETWORK.md](R95-AUDIO-V3-NETWORK.md)；两者是分工关系，不是两套并行方案。

数据来源：用户实车采集包（`car_evidence_20261111` / `car_evidence_20261112/E-20261112`，
SA8295P / Android 12 / build 4040）与实车录入的硬件音效档案（2026-11-24）。
**这些数字无法在本仓库复算**，仓库内只能验证 App 侧行为，车机侧事实以实车为准。

## 1. ADSP 处理顺序（为什么 App 不能随便加正增益）

`/vendor/etc/AudioEffectsManager.xml` 中 `Media` 通道（`streamType="0"`）的串行顺序：

```
agc(2) → be(4) → mdrc(5) → dbb/trb(6–7) → geq(8) → reverb(9) → upmix(10)
      → peq(12) → loudness(14) → crossver(15) → delay(16) → drc(17) → volume(18) → limit(19)
```

- 音量衰减只在第 **18** 级才发生；`mUseFixedVolume=true`，`STREAM_MUSIC` 恒定满格输出全幅
  48 kHz / 16-bit PCM 到 `BUS00_MEDIA`。
- 因此“音量开得不大”并不保护信号：满幅数字信号在到达 `volume` 之前，就先经过 `geq`、`reverb`、
  `drc(17)`，最后撞 `limit(19)`。
- **调音铁律**：车机 EQ 与分声道增益不要全线叠加正增益。全线 +4~5 dB 会让数字满幅信号在
  第 17/19 级被顶穿，听感就是「不大声但发糊、细节没了」——这正是 r92 之前那版 App 的失败模式。

## 2. 0–32 格音量曲线（`LEAP_QC_VOLUME_CURVE_XDC203_B01_14_SS_2ROW.xml`）

`CURVE_MEDIA_LIKE`，Q13 定点（`0x2000 = 0 dB`）：

| 格位 | 1–26 格 | 26–32 格 |
| :--- | :--- | :--- |
| 每格步进 | **+2.0 dB** | **+1.0 dB** |

标定点：10 格 `-38.0 dB`、15 格（默认）`-28.0 dB`、20 格 `-18.0 dB`、26 格 `-6.0 dB`。

**操作结论**：分声道基准整体下调 4 dB 后，日常只需多拧 **2 格**（+4 dB）就回到原来的响度，
同时为 ADSP 前级腾出 4 dB 净空。听感偏轻时拧音量格，**不要**把分声道增益重新拉回去。

## 3. 系统 `LoudnessEnhancer` 已被厂商禁用

`/vendor/etc/audio_effects.xml` 里 `libldnhncr.so` / `loudness_enhancer` 已被注释掉，
系统级响度补偿不可用。动态控制只能在 App 的 PCM 层完成：
`AudioGainProcessor` + `CarAudioDynamicsEngine`。

配套前提（在本仓库可核实）：

| 前提 | 现状 | 位置 |
| :--- | :--- | :--- |
| 软件音效关闭 | 默认 `AudioEffectController.MODE_OFF` | `HawkConfig.HIFI_AUDIO` 默认 0；`CarEnhance.audioMode()` |
| App 增益 100% | 默认 `100`（`VOLUME_GAIN`，0–500） | `HawkConfig.VOLUME_GAIN` |
| 动态处理档位 | 默认 `CAR_BALANCED` | `CarAudioDynamicsEngine.Mode.fromPreference` 兜底 |

## 6. 按听感微调速查表（每次只动 1 项，步长 0.5–1.0 dB）

| 症状 | 动作 |
| :--- | :--- |
| 大动态 / 爆炸 / 鼓点仍轰头或浑浊 | 重低音 `30Hz` `+6.0 → +3.5~4.0`，`65Hz` `+3.0 → +0.5~1.0` |
| 女声齿音（s/sh）或高音偏刺 | 左/右前与中置 `8k`、`14k` 各收 `-1.0`（环绕同步各收 `-1.0`） |
| 对白偏干、缺包围感 / 或仍发散 | 混响在 `0~5` 之间微调（偏干加到 5，偏散收到 0） |
| 高速胎噪大、轻声对白偏小 | 车机不动，App 内把动态档位从 `车载均衡` 切到 `高速压缩` |
| 整体偏轻 | 车机媒体音量多拧 **2 格**（每格 +2 dB），**不要**把分声道增益拉回 `+4~+5 dB` |

## 7. 分工边界（一句话版）

- **车机**：声学补偿（EQ、分声道增益/延时、混响、低频增强）——按第 5 节，加正增益要克制。
- **App**：只做动态（轻声上行抬升、峰值限幅），天花板固定 `-1.5 dBFS`，默认 `车载均衡` + 100% 增益 + 软件音效关。
- 两边同时加正增益 = 重回 r92 之前「不大声但发糊」的老路。
