# r98 · 音频 v4 行车看番双向柔和动态（侧链高通 + 句间保持 + 上端软控）

版本 `3.1.0-car.7-r98` / versionCode 70。只针对 B01（SA8295P / API 32 / arm64-v8a / 2880×1620 / density 160），配套车机硬件音效 `音效aaaa`（详见 [B01-AUDIO-CHAIN-AND-EQ.md](B01-AUDIO-CHAIN-AND-EQ.md)）。

## 1. 实车诊断依据（2026-11-27 行车实录 + R2 云端遥测）

在 `r97` + `音效aaaa` 实车行驶录音（《乱马 1/2》与《穹庐下的魔女》，合计 54 分钟）和同期 R2 日志中，音质清晰无削波，但宽动态番剧在高速工况下仍需频繁手动拧音量，根因共三点：

1. **轻声对白被高速路噪淹没，`CAR_BALANCED` 抬升不足**：实测高速车内人声频段（300 Hz–3.5 kHz）路噪底噪达 `-30.5 dB`（低频 40–250 Hz 达 `-14.7 ~ -18.4 dB`）；音乐人声段在 `-24.7 ~ -25.4 dB`（高出路噪 5–6 dB），而《穹庐下的魔女》轻声对白跌至 `-31.1 ~ -32.4 dB`。R2 日志显示 `CAR_BALANCED (user=1.1)` 对普通对白净 DRC 仅抬 `+1.3 ~ +2.6 dB`，极轻耳语仅抬 `+4.2 ~ +5.0 dB`（`outPeak` 仅 `0.072–0.079`，距 `-1.5 dBFS` 天花板还差 20 dB）。
2. **只抬弱声、不控高潮峰导致拉锯**：拧大音量听清轻声对白后，遇到《乱马 1/2》突发吼叫或《魔女》摇滚 OP（峰值 `+1.9 dB`），v3 阈值以上 0 dB 直通导致瞬间刺耳。
3. **`GATE_DB` 停顿瞬断 + `2000 ms` 慢释放**：日志记录到台词刚停顿 1 s（`19:42:11 → 12`、`19:42:16 → 17`），`gain` 即从 `1.56–1.67` 瞬间摔回 `1.10`，下一句开口又受限于 2 s 慢释放慢慢爬回，造成“句首轻、句尾响”。

## 2. 音频 v4 改动（`CarAudioDynamicsEngine`）

| 项 | r95–r97（v3） | r98（v4） |
| :--- | :--- | :--- |
| 侧链检测 | 全频带 RMS | **250 Hz 一阶高通侧链**（仅影响检测，不改变听感音色） |
| 门限停顿处理 | 低于 `-52 dBFS` 立即摔回 `userGain` | **`1500 ms` 静默保持**，超时后按 `600 ms` 平滑回落至 `1.0` |
| `CAR_BALANCED`（均衡） | 阈值 `-18`，上行 `0.55 / +8.5 dB`，无下行，攻/释 `350 / 2000 ms` | 阈值 `-16`，上行 `0.60 / +10.5 dB`，下行 `0.45 / -3.5 dB`，攻/释 `250 / 800 ms` |
| `CAR_HIGHWAY`（高速） | 阈值 `-16`，上行 `0.65 / +11.5 dB`，无下行，攻/释 `350 / 2000 ms` | 阈值 `-14`，上行 `0.68 / +13.5 dB`，下行 `0.55 / -5.0 dB`，攻/释 `200 / 600 ms` |
| 输出天花板与限幅 | `-1.5 dBFS`（`0.841395`），逐采样 80 ms | 保持不变 |
