## 一、 硬件基准与全局显示规范

| 参数指标 | 硬件实测物理值 | 工程换算标准 | 说明 |
| :--- | :--- | :--- | :--- |
| **屏幕物理尺寸** | 17.3 英寸 | 横向 383 mm，纵向 215 mm | 旗舰座舱宽幅中控屏 |
| **物理分辨率** | **2880 × 1620 px** | 16:9 标准宽屏比例 | 物理像素总量 4,665,600 px |
| **屏幕像素密度** | **160 dpi** (mdpi 基线) | **1 dp = 1 px** | 在 160 dpi 下，Android 系统 `1dp` 精确对应 `1px`，计算零损耗 |
| **物理毫米换算** | 1 mm ≈ 7.52 px | 1 px ≈ 0.133 mm | 车规级防颠簸触控热区最小标准为 **9 mm (68 px)** |
| **默认触控热区** | 按钮高度 ≥ 100 px (13.3 mm) | 间距 ≥ 18 px (2.4 mm) | 彻底消除小按键误触与颠簸点错 |
| **色彩基调 (Obsidian)** | 背景基准：`#0B0F17` | 悬浮面板：`rgba(24, 32, 48, 0.94)` | 高对比防眩光，夜间护眼，白天清晰 |
| **强调色彩** | 科技青：`#00D2FF` | 宝石蓝：`#2563EB` | 状态绿：`#10B981` / 琥珀金：`#F59E0B` |

## 五、 重点交互与后台音频管线工程方案

### 5.1 全屏长按 2.0x 极速快进实现
在播放器视图手势监听器中增加 `OnLongClickListener` / `SimpleOnGestureListener`：
```java
// 播放器手势长按倍速实现逻辑
mGestureDetector = new GestureDetector(context, new GestureDetector.SimpleOnGestureListener() {
    @Override
    public void onLongPress(MotionEvent e) {
        if (!isLocked && mVideoView != null && mVideoView.isPlaying()) {
            mOriginalSpeed = mVideoView.getSpeed();
            mVideoView.setSpeed(2.0f); // 切换为 2.0x 极速快进
            showFastForwardOverlay(true, "⚡ 2.0x 极速快进中...");
            performHapticFeedback(HapticFeedbackConstants.LONG_PRESS);
        }
    }
});

// 在 ACTION_UP / ACTION_CANCEL 时恢复原有播放倍速
@Override
public boolean onTouchEvent(MotionEvent event) {
    if (event.getAction() == MotionEvent.ACTION_UP || event.getAction() == MotionEvent.ACTION_CANCEL) {
        if (mIsFastForwarding) {
            mVideoView.setSpeed(mOriginalSpeed);
            showFastForwardOverlay(false, null);
            mIsFastForwarding = false;
        }
    }
    return mGestureDetector.onTouchEvent(event);
}
```

### 5.2 车机导航与后台音频平稳混音保活
在 Activity 退至后台或切到车机桌面/地图时，不调用 `player.stop()`，保持 IJK / ExoPlayer 音频轨道输出，并请求车载音频焦点 `AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK`：
```java
// 音频焦点请求与混音保活策略
AudioManager audioManager = (AudioManager) getSystemService(Context.AUDIO_SERVICE);
AudioAttributes playbackAttributes = new AudioAttributes.Builder()
        .setUsage(AudioAttributes.USAGE_MEDIA)
        .setContentType(AudioAttributes.CONTENT_TYPE_MOVIE)
        .build();

AudioFocusRequest focusRequest = new AudioFocusRequest.Builder(AudioManager.AUDIOFOCUS_GAIN)
        .setAudioAttributes(playbackAttributes)
        .setAcceptsDelayedFocusGain(true)
        .setOnAudioFocusChangeListener(focusChange -> {
            if (focusChange == AudioManager.AUDIOFOCUS_LOSS_TRANSIENT_CAN_DUCK) {
                // 车机导航播报时自动降低音量至 20%，不中断播放
                setPlayerVolume(0.2f);
            } else if (focusChange == AudioManager.AUDIOFOCUS_GAIN) {
                // 导航播报结束，平滑恢复正常音量
                setPlayerVolume(1.0f);
            }
        })
        .build();
```
