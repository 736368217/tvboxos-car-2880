## 2. 未完成 / 未覆盖（如实说明）

### 2.1 播放相关（含两项增强的运行时验证）——**未完成**
- 本轮测试订阅的站点均为聚合/APP 型站点：搜索结果 0 条、首页卡片进入详情后显示“没找到数据”，未取到可播放直链；因此**没有产生一次真实播放**，导致：
  - 音效链（Equalizer/BassBoost/Virtualizer/LoudnessEnhancer）**未能在真实音频会话上验证**；
  - 臻彩 GL 渲染视图**未能在真实视频上验证**（画面调色/切换/回退）。
- 已准备好的补测物料与步骤（下一轮可直接执行）：
  1. 合成测试片（640×360 / 8s / 440Hz，122KB）已生成于 `cartest.mp4`；
  2. 推入设备 `/sdcard/Movies/` 并触发媒体扫描；
  3. 选择 `本地 • 视频` 作为首页数据源（首页站点名 → “本地 • 视频”），点击该视频进入 `MyVideoView` 播放；
  4. 播放中检查：`dumpsys media_session`（PLAYING）、原生层级出现 `GLSurfaceView`（臻彩生效）、`dumpsys media.audio_flinger` 出现 4 个 AudioEffect（音效生效）、HDR 视频应提示“HDR 视频已自动关闭臻彩”。
- 原因记录：自动化输入对“首页数据源”网格弹窗与本地文件选择器未生效（触摸未选中、DPAD 选中错误项），且实验实例两次被其它会话的应用抢占前台（`com.follow.clash`）与停止，最终在大预算内未完成该项。

### 2.2 其它
- `音效`：仅 EXO/IJK 生效，系统播放器与**直播页**（基类 `VideoView`，无会话访问器）不在范围内。
- `臻彩增强`：切换在**下次播放生效**（渲染视图在 `startPlay()` 时创建）；IJK 的 HDR 判定只有编码名启发式（本 fork 无 color_trc 元数据）。
- 未在真实车机验证：厂商全屏策略、真实 DPI、方控/D-Pad 焦点体验、触摸驱动差异。
- 弹窗类界面（配置地址、选择数据源）为独立窗口：应用内返回按钮位于其下层（设计使然），弹窗用自带按钮/系统返回键关闭。

## 3. 回归结论

- 本轮改动（增强功能 + 规范整改）**未破坏 car.1 的返回按钮行为**，未出现 `FATAL EXCEPTION`；冷启动、配置导入、页面导航均正常。
- 版本 1.0.0-car.2 可交付；播放链路（含两项增强）需按 2.1 的步骤补测后升级结论。
